# Osoora AI Chatbot - Release Notes

## Version 1.0.0

**Release Date:** August 7, 2025

This is the initial release of the Osoora AI Chatbot. This version includes the core features for a fully functional chat application.

### New Features

*   **User Authentication:** Users can create an account, log in, and log out. Sessions are managed with tokens.
*   **Chat Interface:** A clean and intuitive interface for sending and receiving messages.
*   **Real-time Chat:** Real-time messaging with a typing indicator.
*   **Streaming AI Responses:** Responses from the AI are streamed to the user for a more interactive experience.
*   **Conversation History:** All conversations are saved and can be accessed from the chat history sidebar. Users can create new chats, switch between conversations, and delete them.
*   **Markdown and Syntax Highlighting:** The chatbot can format its responses with Markdown, and code blocks are automatically highlighted.
*   **Theme Customization:** Users can switch between light and dark themes.
*   **User Profile Management:** Users can update their username and password.

### Known Issues

*   There are no known issues at this time.
